# Мини Социальная Сеть
Собственно, ваш проект. Может звучать сложно, но по факту это не так.

## Фронтенд
1. Лента постов
2. Страница отдельного поста
3. Лайки без перезагрузки страницы
4. Переключение тем

## Бекенд
1. CRUD для постов (Create, Read, Update, Delete)
Примерные поля, которые должны быть у каждого поста:
  - id (int)
  - name
  - contents
  - count_likes (int >= 0)
2. Аутентификация по паролю (гуглить http base auth)
